# T-Dongle-S3 Screen BLE RU v11

Прошивка для LILYGO T-Dongle-S3 V1.1 с дисплеем ST7735 80×160.

## Что изменилось в v11

- Исправлено подключение с Samsung Galaxy S25 Ultra и Chrome: удалён ненадёжный
  системный диалог BLE-сопряжения из v10.
- Удалены системное BLE-сопряжение и прикладная проверка PIN.
- После выбора `Клавиатура` в веб-панели текст, клавиши и мышь доступны сразу.
- Добавлены `Backspace`, `Delete`, `Копировать`, `Вставить`, `Вырезать`,
  `Выделить всё` и `Отменить`.
- `Контекстное меню` отправляет `Shift+F10`.
- `Свойства` отправляет `Alt+Enter`.
- Backspace и Delete можно удерживать для непрерывного удаления.
- На сенсорной площадке касание выполняет левый клик, а удержание — правый.
- Сохранены отдельные кнопки левого, правого и среднего клика и прокрутки.
- Страница не содержит аналитики, внешних скриптов или сетевой отправки текста.

## Настройки

- Имя BLE и Wi-Fi: `Клавиатура`.
- Пароль резервного Wi-Fi: `12345678`.
- BLE запускается автоматически.
- Заставка показывается 4 секунды.
- Русский UTF-8 преобразуется в физические клавиши раскладки ЙЦУКЕН.
- Для надёжной печати нажатие и отпускание каждой клавиши выдерживаются по 8 мс.

Пароль Wi-Fi оставлен прежним для совместимости. Это простой пароль: Wi-Fi-режим
следует включать только там, где поблизости нет посторонних пользователей.

## Подключение

Откройте в Chrome или Edge:

https://labeckiys.github.io/esp32-s3-cyrillic-hid/

Нажмите «Подключить устройство» и выберите `Клавиатура`. После подключения можно
сразу отправлять текст и использовать клавиши и мышь.

## Сборка и загрузка

1. Откройте всю папку `firmware/lilygo-cyrillic-v11` в VS Code с PlatformIO.
2. Нажмите `Build` (галочка).
3. Отключите донгл, зажмите боковую кнопку, вставьте его в USB и отпустите через 2–3 секунды.
4. Нажмите `Upload` (стрелка вправо).
5. После `SUCCESS` переподключите донгл без зажатой кнопки.

Среда PlatformIO: `lilygo-t-dongle-s3-screen-v11`.
