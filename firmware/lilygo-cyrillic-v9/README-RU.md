# T-Dongle-S3 Screen BLE RU v9

Прошивка для LILYGO T-Dongle-S3 V1.1 с дисплеем ST7735 80x160.

## Настройки

- Имя BLE и Wi-Fi: `Клавиатура`
- Пароль резервного Wi-Fi: `12345678`
- BLE запускается автоматически после подачи питания.
- Экран работает вертикально. Заставка изначально нарисована в пропорции 1:2:
  звезда нормальной формы расположена сверху, надпись «КИБЕР РФ» и триколор — ниже.
- Изображение занимает всю область дисплея 80×160 без геометрического растяжения.
- При включении заставка показывается 4 секунды, затем отображается
  адаптированный вертикальный статус BLE.
- Экран сразу обновляет статус при подключении и отключении телефона.
- После отключения BLE-реклама запускается повторно автоматически.
- Кнопка `Win/Cmd` в веб-панели отправляет `Win+Space`.
- Поддерживается русский UTF-8, включая `ё`, заглавные буквы и основные знаки.
- Исправлена потеря отдельных букв при длинной печати: каждое HID-нажатие и
  отпускание теперь выдерживается отдельно по 8 мс.

## Раскладка

USB HID отправляет физические клавиши, поэтому раскладку выбирает целевой компьютер:

- перед русским текстом включите `RUS` кнопкой `Win/Cmd`;
- перед командами и английским текстом включите `ENG`.

Панель управления:

https://kolec94.github.io/esp32-s3-hid-dongle/web/control.html

## Сборка и загрузка

1. Откройте всю папку проекта в VS Code с PlatformIO.
2. Нажмите `Build` (галочка).
3. Отключите донгл, зажмите боковую кнопку, вставьте его в USB и отпустите через 2-3 секунды.
4. Нажмите `Upload` (стрелка вправо).
5. После `SUCCESS` переподключите донгл без кнопки.

Готовая заставка включена в
`boards/cyber_star_v8_splash.h` в формате RGB565 80×160.
